BDH-CQ: In-Context Learning with Recurrent Latent Reasoning
arXiv FLAGSHIP 2026-08-10 ▲ 772 Björn Engdahl 외

BDH-CQ 모델은 in-context learning과 recurrent latent reasoning을 결합한 추론 모델이다. 입력 데이터가 추론 과정에서 모델의 재귀 메모리를 지속적으로 업데이트하고, 고차원 잠재 공간에서 반복적인 계산을 통해 쿼리를 해결한다. 150M 파라미터 구성은 ARC-AGI-1 평가 세트에서 29.5%의 pass@2 성능을 달성하며, 계산 추론 비용은 $0.0007로, 기존의 비용-정확도 패레토 프런티어를 뛰어넘는 새로운 기준을 세웠다.

Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills
arXiv FLAGSHIP 2026-09-02 ▲ 522 Jianlyu Chen 외

StudentSim: Training LLM-based Student Simulators
arXiv FLAGSHIP 2026-09-01 ▲ 482 Ke Yang 외

AI 튜터가 각 학생의 강점, 약점, 선호하는 지도 방식에 맞춰 적응하는 문제를 다룬다. StudentSim은 희박한 개인 데이터를 통합 학습과 개인별 특화를 통해 개인화된 시뮬레이터를 생성한다. StudentSim은 체스, 영어 작문, 수학에서 GPT-5.4보다 높은 F=0.51, R=0.91의 성능을 보여, 튜터 강화 학습에 활용될 때 전문가에게 더 정확하고 개인화된 지도를 제공한다.
